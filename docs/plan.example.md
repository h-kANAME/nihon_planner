#### ¿Día completo o combinable?


| Criterio                                                  | Veredicto                                                                                                     |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| ¿Bloquea el día como Disney/USJ?                          | **No.** No exige 10–12 h in-park.                                                                             |
| ¿Hay que “reservarlo” como día entero en el plan?         | **Sí como actividad principal del día** (slot + 4–6 h + traslado), pero **no** como día cerrado sin nada más. |
| ¿Combinable?                                              | **Sí, con bloque tarde/noche ligero en Ikebukuro** (está a 17 min).                                           |
| ¿Combinable con Odaiba / teamLab / Yokohama el mismo día? | **No recomendado** — segundo “plato fuerte” + traslados largos.                                               |


**Recomendación de planificación**

1. **Slot mañana** (aprox. 10:00–11:30): aprovechan el tour sin prisa.
2. Salida del studio ~15:00–17:00 según ritmo.
3. **Combinar solo con Ikebukuro** (compras pendientes, cena, Animate/Sunshine si no se agotaron el día 4).
4. Si el grupo es *superfan* (6 h + shop): tratarlo casi como día dedicado; la “combinación” = solo cena cerca del hotel.
